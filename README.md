# Faris · فارس

Learn and play chess with a patient AI coach — in Arabic and English.

| Folder | Contents |
|---|---|
| [`mobile/`](mobile/) | Flutter app (Flame board) |
| [`packages/chess_core/`](packages/chess_core/) | Pure Dart chess rules engine |
| [`backend/`](backend/) | .NET 9 modular backend (SignalR for online play) |
| [`ai-service/`](ai-service/) | Python coach service (engine facts → explanations, RAG over lessons) |
| [`frontend/`](frontend/) | Angular + Nx: parent dashboard and content admin |
| [`docs/`](docs/) | Game design, brand kit, architecture |

Start with [`CLAUDE.md`](CLAUDE.md) for the rules that apply everywhere; each folder has its own `CLAUDE.md`.
